# Mirror Civilizations · 镜像文明

A bilingual atlas mapping the cities and regions of China to their structural counterparts in Europe — built on three deep parallels: BaiYue ↔ Latin, Northern Mandarin ↔ Germanic, Yangtze ↔ Mediterranean. 25 pairs, each with its own deep-dive page.
